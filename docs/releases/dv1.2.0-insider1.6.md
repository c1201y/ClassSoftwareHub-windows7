# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.6 预览版发布

前言
--

* 本版为 **dv1.2.0 预览线的新版本**，在 dv1.2.0-insider1.5 的基础上引入桌面端正版校验与官方构建签名，同时完成 Windows 7 窗口材质、提示音与触屏点击的修复。

* **官方发布包自带构建签名**，在线服务无需任何操作即可使用。自行编译或改动过的版本，需要使用在线功能（软件投稿、反馈中心、回声洞、教室喊话、下载加速）时输入激活码。

* 预览版面向 insider 通道用户。若正在使用 dv1.2.0-insider1.5，建议升级。

更新日志
----

* 【新增】**正版校验与官方构建签名**：签名在发布阶段写入程序集元数据，不再以独立文件随包分发；每个在线请求携带构建号、签名与设备码，服务端验签通过后自动签发授权令牌，官方版本全程无感。令牌有效期 30 天，到期自动重新签发。

* 【新增】**激活与授权提示**：设置页新增「授权 → 正版授权」，可查看设备码并输入激活码，授权有效期一年。未激活时首次进入需要在线服务的页面（提交软件、教室喊话、反馈中心、反馈表单、系统镜像、软件列表）会提示一次，选择「以后再说」后本次运行内该页不再重复提示；提示中同时提供「打开官网下载官方版」入口，可直接获取无需激活的官方发布包。

* 【优化】**Windows 7 窗口材质**：移除在 Windows 7 上模拟的半透明效果，改为取当前壁纸缩放后叠加主题色，一次性烘焙为不透明底色。不抓取屏幕、运行期无额外开销，拖动与缩放窗口不重新计算。

* 【修复】**Windows 7 提示音无声**：MP3 播放改用 8.3 短路径调用 MCI，含中文与空格的路径不再失败；播放异常时给出可读原因，并在播放后校验播放进度，静默失败写入运行日志。

* 【修复】**触屏滚动被识别为点击**：系统修复、化学、方程式编辑器、磁盘占用四页改为抬手且位移在阈值内才判定为点击。

* 【修复】**长时间运行的资源占用**：时钟背景位图替换时释放旧图，窗口图标句柄显式销毁，时钟工具照片缓存限制为 8 条。

* 【优化】**教室喊话接收**：连续连接失败达到 5 次后退避 1 秒，避免在断网或服务不可达时持续重试。

* 【优化】**在线请求出口统一**：投稿、回声洞、喊话、镜像签名与 OSS 上传统一走同一请求入口，修复 Windows 7 上投稿页因 TLS 版本默认值导致的连接失败。

* 【优化】**代码注释精简**：清理冗余注释，不改变功能、界面与数据格式。
