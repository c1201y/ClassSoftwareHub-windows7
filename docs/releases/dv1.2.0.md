# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0 正式版发布

前言
--

* 本版是 **dv1.2.0 线的正式版**，基于 dv1.2.0-insider1.10，在打正式版之前做了一轮**全项目缺陷审计 + 修复**：重点修掉了化学配平「一价离子全被拒」、方程求解「大根漏解 / 科学计数法被当变量名 / 边输边校验会崩」、函数绘图「陡直线整条消失」、32 位系统「桌面留言透明必失效」，以及 AI 对话「点一次停止后该会话每问必报错」这几处影响最大的问题。

* **API 与数据结构向后兼容**：可以直接覆盖升级，课表、课件记录、设置、AI 会话历史都不受影响。

* 官方发布包自带构建签名，在线服务无需任何操作即可使用。自行编译或改动过的版本，使用在线功能（软件投稿、反馈中心、回声洞、教室喊话、下载加速）时需要输入激活码。

* **本版是正式版，走 stable 通道**。之前用 insider 预览版的同学：客户端仍能收到本版（预览通道也看正式 Release），升级后即回到正式版序列。

* 本版已对齐上游 **dv1.2.0 正式版**（含此前漏移植的 **dv1.2.0-insider1.11** 全部内容）。


对齐上游 dv1.2.0 正式版（本次补移植）
--

### 授权状态

* **官方发布版不再显示「输入激活码」按钮**。此前官方版也摆着这个按钮，点下去只会念一遍状态 —— 让人误以为"这版还要激活"。现在官方版与已激活版本都只展示状态。

* **激活后显示激活时间，不再显示有效期**。有效期是服务端签发令牌的属性，对用户没有可操作含义，反而容易被误读成"这软件快到期、到期就不能用了"。

### 系统工具（五项转正）

* **系统优化、系统功能、虚拟内存、幽灵文件清理、PowerPoint 触控优化** 五项退出「实验性功能」，移入「系统工具」。页面标题旁的「实验性功能」标记随之消失。

* 转正后这五项在「设置 > 自定义导航栏」里也能像其他系统工具一样调整位置。

### PowerPoint 触控优化

* **用笔、荧光笔、橡皮或激光笔时不再触发翻页**。此前老师拿着笔在屏幕上写字，抬笔那一下时间短、位移小，正好符合"轻点"判据，于是刚写完一横就翻到下一页 —— 这是上课时最要命的误触。现在切到这些工具后，轻点与上下滑都不再被当作翻页（菜单里的「上一页 / 下一页」仍然可用）。

* **能识别用 PowerPoint 自带快捷键切过去的笔模式**。判定方式从「只记我们自己菜单里选了什么」升级为「直接问 Office 当前指针类型」（读 `SlideShowView.PointerType`），因此用 PPT 自带的右键菜单、`Ctrl+P` 切到笔，本程序同样知道，不会误翻页。读不到状态时（未装 PowerPoint、WPS 演示）自动退回原来的判定，不误伤原有手势。

### 版本号显示

* **预览版在界面上显示为 `Pr`**（`1.2.0-insider1.11` → `1.2.0-Pr1.11`），与正式版一眼区分，也不再给用户看内部术语 insider。版本比较、更新判定仍用原始版本号，不受影响。

### Hub AI

* **编辑已有模型时，密钥框不再显示成空白**，改为提示「密钥已保存（留空表示不修改，重新填写则覆盖）」。此前空白输入框会让人以为密钥丢了、要重填一遍。

* **没填密钥的模型不能保存**，保存后也不会被自动设为当前模型。此前会出现一条"看着配好了、一问就报错"的模型，用户得自己猜漏了哪一步。

* 删除全部模型后，重新进入设置页保持为空，不再自行出现一条未配置的模型（此项本移植版原本已正确，本次核对确认）。


本次修复（相对 dv1.2.0-insider1.10）
--

### 化学方程式配平

* **修掉「一价离子一律配不平」**。此前 `H^+`、`OH^-`、`NO3^-`、`NH4^+`、`Cl^-` 这些**软件自己预置在「常用离子根」面板里的按钮，点下去配平会直接报错**（8 个默认离子有 5 个用不了），而报错提示里举的例子 `NH4^+` 自己也是坏的，用户无路可走。现在全部可用。

* **新增电荷守恒校验**。离子方程式除了元素守恒，现在还会核对左右总电荷；电荷不平会明确报错（例如 `Fe^2+ = Fe^3+` 不再被当成「配平成功」）。结果区会多出一行「电荷」核对。

* 正常方程式回归验证：`4Fe + 3O2 = 2Fe2O3`、`C2H5OH + 3O2 = 2CO2 + 3H2O`、结晶水、括号嵌套全部正确。

### 方程求解

* **大根不再漏解**。`x^2 = 1e10` 以前只给一个正根（应为 ±100000），`x^2 = 1e12` 直接报「没有找到实根」；现在都对。

* **科学计数法能用了**。`x = 1e10`、`x + 1e2 = 300` 以前会把 `1e10` 拆成「1 × 未知数 e10」，答成「无穷多组解」且不报错；现在正确算出数值。

* **修掉会崩的输入**。`x ^ a`、`x ^ (2)`、`x^999999999999999999999` 这类写在输入框里可能正在打的式子，以前会抛异常打穿界面（方程页是边输边校验的）；现在会给出正常的「式子看不懂」提示。

* 恒等式（`x^0 = 1`）现在报「任意实数」，不再只显示 `x = 0`。

### 函数图像

* **陡直线不再整条消失**。`y = 2000x` 及以上、以及放大后的陡峭区段，以前会画成空白图（被误判成渐近线）；现在正常绘制。真正的不连续（`1/x`、`tan(x)`）仍然正确断开。

### Windows 7 / 平台

* **修掉 32 位系统上「桌面留言」透明失效**。32 位 user32 里没有 `GetWindowLongPtrW` 这个导出，以前调用会抛异常后被静默吞掉；现在按进程位宽路由到正确的 `GetWindowLongW`。

### AI 对话

* **修掉「点一次停止，之后每问必报错」**。历史里出现半应答的工具调用时，用于修复历史配对的函数自己会造出孤儿 tool 消息，服务端一律 400。现在改为成组暂存，答全才落盘。

* **回答被截断会提示**。此前从不检查 `finish_reason`，服务端因长度上限截断时用户看到的半截结论与完整回答没有区别；现在会明确提示，并在正文末尾标注。

* 流式解析同时修了三个洞：多行 `data:` 拼接、UTF-8 BOM 首行、`[DONE]` 之后不再空等到超时。

### 界面

* **初次配置向导 10 个页面补上滚动条**。窗口较小或系统缩放较大时（如 1366×768 @150%），页面内容会被裁掉且没有任何提示；现在可以滚动。

* **自检覆盖面从 11 个资源键扩到 70 个**（35 个键 × 浅色/深色两套主题）。此前引用量最大的三个键（卡片描边、卡片底色、次要文字）不在检查范围里 —— 它们一旦在依赖升级时改名，104 个界面的卡片会同时静默变透明，而自检仍然全绿。

### PPT 续播

* **悬浮窗可以选任意科目续播**。科目改为下拉选择，列出「课表里的科目 + 有进度记录的科目」的并集 —— 上一节数学没讲完，课间可以直接选数学续上，不必等课表切到那一节；临时调课、或没导入课表也能用。

* 手动选过的科目不会被自动识别的「当前这一节」覆盖回来。

* 没记录过的科目也能直接「给这个科目选课件」，选完即可续播。


运行前提（Windows 7 必看）
--

Windows 7 上除了 SP1，还需要一个系统更新：

| 更新 | 必要性 | 说明 |
| --- | --- | --- |
| **KB3063858** | **必须** | 早期版本号 KB2533623，现已并入后续累积更新。它给系统补上 `SetDefaultDllDirectories` 等一组 DLL 目录 API —— .NET 6 运行时靠这组 API 加载自己的组件。 |

缺这个更新的表现：双击程序**闪一下就退出**，界面上没有任何提示；打开「事件查看器 → Windows 日志 → 应用程序」能看到「事件 1023，.NET Runtime」，详细信息形如 `Failed to load the dll from [...hostfxr.dll]`、HRESULT `0x80070057`。

解决办法：到微软更新目录（catalog.update.microsoft.com）搜 `KB3063858` 装上，装完提示重启就重启。教室里的机器一般由管理员统一打补丁，把这个编号告诉老师即可。

已知限制
--

* 需要真机验证的观感项（自绘标题栏拖动手感、Aero / 亚克力材质在具体显卡上的表现、多屏不同缩放）本次只做了代码层修正，未在真机逐一目视。
* **PPT 笔模式识别的 COM 链路未在真机实测**：读 `SlideShowView.PointerType` 这段代码已移植并编译通过，但「真能读到 PowerPoint 的指针类型」必须在装了 PowerPoint 并实际放映的机器上确认。读不到时会自动降级为「按箭头处理」，不影响其他功能。
* 「残留清理」的提权清单仍是「同用户可写目录 → 管理员进程读取」的模型，理论上同用户进程可在 UAC 弹窗期间替换清单。这是已知的加固项，后续版本会改为助手侧重算候选。
* 教室喊话的局域网凭证目前是明文广播，仅适用于可信内网。
