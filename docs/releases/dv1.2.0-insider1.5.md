# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.5 预览版发布

前言
--

* 本版为 **dv1.2.0 预览线的新版本**，完整对齐上游桌面版 dv1.2.0-insider1.8 的功能集：新增初次配置向导、系统功能、系统优化、虚拟内存、查阅单词、哈希校验与 Hub AI 浮层，并包含 dv1.2.0-insider1.4 的全部改进。

* **初次配置向导**只在新装首次启动时出现；已有存档的升级用户不受影响，存档中没有向导记录时按已完成处理，不会被打断。

* 预览版面向 insider 通道用户。若正在使用 dv1.2.0-insider1.4，建议升级。

更新日志
----

* 【新增】**初次配置向导**：欢迎、用户协议、检查更新、外观、侧边工具栏、侧边栏位置与尺寸、截图、开机启动、下载位置、Hub AI 与完成页共十二步；外观页的主题与窗口材质当场预览，选择写入设置后主界面直接生效。向导可随时关闭，未完成时下次启动继续。

* 【新增】**系统功能**：机器级系统项（注册表 `HKLM` 与 `powercfg`）集中开关，进入页面时从系统实时读取状态；改动只排队，点一次授权统一写入，需要重启的项单独标注。

* 【新增】**系统优化**：任务栏、搜索框、文件扩展名、透明效果、建议内容等当前用户设置分组呈现；按系统版本自动停用不适用项；统一应用后通知外壳刷新，不再默认结束资源管理器。

* 【新增】**虚拟内存**：按驱动器设置分页文件（自定义大小 / 系统管理 / 无），排队后一次授权写入并回读校验。

* 【新增】**查阅单词**：内置离线词库，支持单词查询与整句翻译；词源四档优先级（离线优先 / 在线优先 / 仅离线 / 仅在线），离线优先时在线查到的词会补进本地词库，并保留最近十条查询历史。侧边栏提供 480×640 小浮窗，可一直摆在角落。

* 【新增】**编码 / 哈希校验浮窗**：拖入文件立即计算 MD5、SHA-1、SHA-256、SHA-512，粘贴发布方给出的校验值自动比对；只在本机计算，不上传。

* 【新增】**应用链接（`csh://`）**：支持跳转到页面、内置工具、设置分组与系统设置；从浏览器或文档唤起时，链接会转交给正在运行的实例处理。

* 【新增】**Hub AI 浮层与页面上下文**：软件下载、AppData 管理、应用卸载、系统功能、系统优化、虚拟内存、查阅单词等页面提供提问入口，浮层与 Hub AI 页共用同一份会话与工具；发送时把当前页的现场数据生成结构化 JSON 交给模型；单轮问答按时间预算控制，停止时说明原因。

* 【新增】**下载位置**：设置页可指定默认下载文件夹；详情页下载时可临时选择「下载到其他文件夹」，不影响默认值；重试沿用同一目录。

* 【新增】**AppData 管理清理任务**：清理进度进入「任务进行」页，切走页面后仍可查看；清掉一部分、剩余文件被占用时按部分完成处理并单独说明，只有整个目录一个文件都没删掉才算未完成。

* 【新增】**局域网喊话发送页**：手机访问本机喊话地址即可打开内置发送页，不必再依赖外部页面。

* 【优化】**导航与首页**：函数图像从课堂工具提为独立功能项；白板专杀、AppData 管理、系统修复自实验性功能转正；侧边栏支持长名按钮。

* 【优化】**窗口材质**：Windows 7 主窗口改用静态磨砂——窗口渐变底加标题栏、导航栏半透明罩，复现只有标题栏和导航栏是玻璃的分层，不抓屏、无额外开销；Windows 10 选择「云母」时回退系统亚克力，不再直接落到纯色。

* 【优化】**界面细节**：任务卡片、列表与浮窗的圆角、按钮与留白统一，音量窗等常用窗口跟随主题与自绘边框。

* 【修复】**教室喊话接收**：入口连接类失败（连接被拒、TLS 握手失败）当场重试一次，超时不重试；改善信号良好时仍偶发收不到的问题。

* 【修复】**下载与镜像**：下载任务区分更新包、普通下载与本地清理，图标与可用按钮分别处理；IP 直连反代只代理 `github.com` 路径，不再对其他主机做无效尝试。

* 【同 1.4】文件快搜、PPT 续播、托盘自绘菜单、桌面留言改版、窗口与侧边栏调整，以及安全、数学化学、桌面系统与工具交互方面的修复，详见 dv1.2.0-insider1.4 发布说明。
