# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.0 预览版发布

前言
--

* 这是 Windows 7 移植版的 **dv1.2.0 预览线第一个版本**：完整对齐上游桌面版 dv1.2.0-insider1.1 的功能集，界面与交互继续与原版 1:1 对齐。为对齐上游，直接升级版本号至 dv1.2.0

* 预览版面向 insider 通道用户，用于在正式版发布前验证新功能与修复；发现问题可在反馈中心提交。

更新日志
----

* 【新增】**首页推荐应用**：新增近期新增应用的横向滚动推荐条，悬停暂停、可一键换一批；快捷链接升级为 SVG 矢量图标并跟随主题变色。[by@椰汁](https://afdian.com/a/cyan1201)

* 【新增】**软件详情页改版**：渐变头图、双栏正文布局、相关推荐侧栏、分隔线式信息区；下载入口支持商店 / 文件 / 网盘 / 网页多种类型。[by@椰汁](https://afdian.com/a/cyan1201)

* 【新增】**更新日志页改版**：左侧版本列表 + 右侧文档式正文，支持按类型筛选与点击定位滚动。[by@椰汁](https://afdian.com/a/cyan1201)

* 【新增】**内置工具**：函数图像、方程求解、化学方程式配平、磁盘空间、应用卸载、应用数据清理、开机启动项、系统修复；「自动关机」自实验性功能转正，并新增「套用前一天」。[by@椰汁](https://afdian.com/a/cyan1201)

* 【新增】**侧边栏细线折叠条**与贴边隐形热区：折叠后只剩一条细线，贴边悬停即可唤出。[by@椰汁](https://afdian.com/a/cyan1201)

* 【优化】内置工具、实验性功能改为双栏导航卡片布局；导航栏图标增大。[by@椰汁](https://afdian.com/a/cyan1201)

* 【优化】更新器下载校验失败时自动切换线路；下载进度同时接入前台对话框与后台任务；窗口位置与最大化状态随会话记忆。[by@椰汁](https://afdian.com/a/cyan1201)

* 【修复】方程求解、化学配平等页面的**公式不显示**；化学方程式条件文字被裁剪。[by@椰汁](https://afdian.com/a/cyan1201)

* 【修复】特定滚动状态下可能触发的**栈溢出崩溃**（0xC00000FD）：滚动偏移写入增加数值有效性校验。[by@椰汁](https://afdian.com/a/cyan1201)

* 【修复】标题栏**搜索框无法点击**；「系统镜像下载」打开为首页；日志详细视图未跟随主界面深浅色。[by@椰汁](https://afdian.com/a/cyan1201)

* 【修复】搜索、函数图像、方程求解、磁盘空间、教室喊话、图片取色的**图标字形错误**（内嵌图标字体补绑码位）。[by@椰汁](https://afdian.com/a/cyan1201)
