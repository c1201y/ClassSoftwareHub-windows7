# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.10 预览版发布

前言
--

* 本版在 dv1.2.0-insider1.7 的基础上，对齐上游桌面端 **dv1.2.0-insider1.9 与 dv1.2.0-insider1.10** 的功能增量：文档库、PowerPoint 触控优化、幽灵文件清理、实验性功能标记统一、导航栏布局自定义、首页公告、图片取色浮窗、在线条款、虚拟内存系统盘锁定、对话内可点动作。

* 官方发布包自带构建签名，在线服务无需任何操作即可使用。自行编译或改动过的版本，使用在线功能（软件投稿、反馈中心、回声洞、教室喊话、下载加速）时需要输入激活码。

* 预览版面向 insider 通道用户。若正在使用 dv1.2.0-insider1.7，建议升级。

运行前提（Windows 7 必看）
--

Windows 7 上除了 SP1，还需要一个系统更新：

| 更新 | 必要性 | 说明 |
| --- | --- | --- |
| **KB3063858** | **必须** | 早期版本号 KB2533623，现已并入后续累积更新。它给系统补上 `SetDefaultDllDirectories` 等一组 DLL 目录 API —— .NET 6 运行时靠这组 API 加载自己的组件。 |

缺这个更新的表现：双击程序**闪一下就退出**，界面上没有任何提示；打开「事件查看器 → Windows 日志 → 应用程序」能看到「事件 1023，.NET Runtime」，详细信息形如 `Failed to load the dll from [...hostfxr.dll]`、HRESULT `0x80070057`。

解决办法：到微软更新目录（catalog.update.microsoft.com）搜 `KB3063858` 装上，装完提示重启就重启。教室里的机器一般由管理员统一打补丁，把这个编号告诉老师即可。

**不需要额外安装**（安装包与便携包都是自包含部署）：

* .NET 6 运行时 —— 运行时就带在程序目录里；
* VC++ 运行库 —— UCRT 已随包（`ucrtbase.dll` 与 15 个 `api-ms-win-crt-*.dll`）。实测包内 263 个原生模块**没有一个**依赖 `vcruntime140.dll` / `msvcp140.dll`，所以不必装 VC++ Redistributable。

更新日志
----

* 【新增】**文档库**：电脑优化与使用技巧的图文教程，正文按需下载（Markdown / 纯文本 / docx 原生渲染），支持按标题、简介、作者与标签检索；文章内容放在独立的内容仓库，客户端只缓存清单与读过的正文，缓存文件名改为随机串。

* 【新增】**PowerPoint 触控优化**（实验性）：放映时单击翻页、长按弹出本程序的放映菜单（上一页 / 下一页 / 画笔 / 指针 / 结束放映等），替代 PowerPoint 原生那个不适合触屏的菜单。

* 【新增】**幽灵文件清理**（实验性）：扫描删不掉、双击提示找不到路径的残留条目（`\\?\` 长路径、末尾带空格的非法名），删除优先走回收站；磁盘根、Windows、Program Files、ProgramData 及用户目录根等位置只做检查、不执行删除。

* 【新增】**导航栏布局自定义**：设置 → 侧边栏导航里可以把「查阅单词 / 文档库 / 教室喊话」收进分组，也能把常用工具拎到一级，勾选立即生效；分类归属不开放修改，实验性功能的页面始终留在分组内。

* 【新增】**首页公告**：首页大标题下方的公告条，按版本与通用两档下发，每条互相独立；公告走代码托管通道读取，后端不可用时依然能发出去。

* 【新增】**图片取色浮窗**：侧边栏「取色」不再拉起主界面，改为弹出一扇小浮窗（与哈希校验、查阅单词同一套形态），内容与整页共用同一份取色算法。

* 【新增】**对话内可点动作**：Hub AI 的回复末尾可以带一排按钮（切换深浅色主题、跳到对应设置页或工具页），按钮文案与去处由程序固定，模型只能挑用哪个；点了才生效，模型本身不改任何东西。

* 【新增】**Hub AI 接入文档库**：助手可以查文档库清单、读某篇文章的正文再照着讲解，用户问「有没有关于……的教程」时不必自己翻。

* 【新增】**在线条款**：用户协议、隐私政策、免责声明改为启动后从站点拉取最新版本，站点改完提交即生效，不必等下一次发版；离线或全部线路失败时回退内置副本。

* 【新增】**虚拟内存 · 系统盘分页文件锁定**：在原有逐盘设置之上增加「系统盘分页文件锁定」开关，与其它改动一样排队后一次授权写入、重启生效。

* 【优化】**实验性功能标记**：各页标题旁的「实验性功能」胶囊收成一个共用控件，显示与否由功能清单决定；功能转正时从清单删一条即可，不再出现"有的页面有、有的页面忘加"。

* 【优化】**导航角标**：新功能入口旁的 New / Beta 角标只在本版本装好后的前 15 天内显示，过期自动消失，不必每次发版手动维护。

* 【优化】**界面字体**：全站默认字体改为随程序内嵌的 **HarmonyOS Sans SC**（Light / Medium / Bold 三档字重），Windows 7 上不再回落到宋体的点阵渲染 —— 小字号正文、导航项、对话框标题都变成统一的黑体观感，加粗标题用真粗体而不是合成粗体。字体按 HarmonyOS Sans 字体授权协议随程序分发，设置 → 关于 里有对应声明。

* 【优化】**音量 / 亮度浮窗外观**：跟随侧边栏那套外观设置（原先跟应用主题，导致「应用深色 + 侧边栏浅色」时两者一黑一白）。

* 【优化】**软件详情**：补充开发者与开源协议两行，存在本站对象存储的软件会标注来源。

* 【修复】**条款与公告的网络兼容**：这些通道在 Windows 7 上显式启用 TLS 1.2。

* 【修复】**窗口背景材质 · 亚克力**：Windows 11 上「亚克力」此前套的是 Mica Alt 背板（云母的变体），所以观感和云母几乎一样。现改用系统真正的亚克力材质 —— 实时模糊窗口背后的画面、带一层颗粒，和云母一眼能分开；系统版本不认这个材质时会自动退到 Mica Alt、再退云母，不会掉成「透明但没材质」。
* 【修复】**本机核实的软件卡片**：卡片里的版本信息（本机版本 → 清单版本）不再顶出卡片边界，过长时正确显示省略号，鼠标悬停可看完整内容。

* 【修复】**直达折叠分组内的页面时崩溃**：以「实验性功能」分组里的页面作为起始页（命令行 `--page=<tag>`、外部链接跳转）会让程序在窗口显示后约 4 秒退出，现改为等导航面板铺开后再点亮高亮。
* 【修复】**日志页滚动乱跳**：日志内容折行使每行高度不一，虚拟化列表的总高估算随着滚动不断被修正 —— 滑动条滑块会自己变长变短、位置乱跳，按住拖动也会被回弹。现改为固定行高的单行显示（过长内容悬停看全文，双击该行进「详细视图」看完整堆栈），滚动完全跟手。

## 已知差异（与上游桌面版不同，属移植取舍）

* 文档库里的 **PDF** 正文不做内嵌渲染（Windows 7 没有 WinRT 的 PDF 组件），改为「用系统默认程序打开」。
* 授权模块沿用本移植版既有的 `ClientAuthHandler + LicenseGate + ActivationDialog` 架构（比上游多一步「激活成功后原样重放请求」），未按上游文件名重建，避免同一台机器出现两套设备标识。
* `--window=<模块 id>` 启动参数未移植：本移植版的浮窗分发走 `SidebarModule.WindowTool` 字符串，与上游的 `WindowType` 反射不是一套。
* PowerPoint 触控的长按菜单是本程序自绘的圆角卡片，外观与上游的系统菜单不完全一致（Windows 7 没有逐像素透明，系统浮层那套不可控）。
* 公告的「上次可用线路」与公告正文都只在本次运行内保留，不落盘：断网启动且本次尚未联网成功时看不到公告。
