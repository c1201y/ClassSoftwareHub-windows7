# ClassSoftwareHub 桌面版（Windows 7）dv1.2.1 正式版发布

前言
--

* 本版为 **dv1.2.1 正式版**，内容为对齐上游 **dv1.2.2 正式版**（含此前未移植的 **dv1.2.1** 全部内容），并在移植过程中修掉了本版实测发现的问题。

* **API 与数据结构向后兼容**：可直接覆盖升级，课表、课件记录、设置、AI 会话历史不受影响。

* 官方发布包自带构建签名，在线服务无需任何操作即可使用。自行编译或改动过的版本，使用在线功能（软件投稿、反馈中心、回声洞、教室喊话、下载加速）时需要输入激活码。

* **本版走 stable 通道**。此前用 insider 预览版的用户，客户端仍能收到本版，升级后回到正式版序列。


投稿向导（新）
--

软件投稿由单页表单改为**分步向导**，共五步：从 GitHub 读取、软件信息、安装包与系统、补充信息、核对并提交。

* **关闭窗口自动保存草稿**，下次打开自动带出，中途退出不会白填。

* **可从 GitHub 仓库读取并自动填入**名称、简介、官网、开发者、开源协议与版本号；默认只补空白项，已填写的内容保留。

* **软件 ID 随名称自动生成**，中文名按拼音转写（「网易云音乐」→ `wangyiyunyinyue`）。ID 会实时校验格式与是否与站内已有软件重名，并给出详情页地址预览；手动修改后名称再变也不会覆盖。

* **支持把安装包与图标直接上传到本站存储**，不必自备网盘。上传显示进度，完成后自动回填地址并锁定输入框。

* 下载项最多五条，每条可单独设置平台、体积、备注、下载方式与校验值；常用项直接填写，其余收在「更多选项」内。

* 提交前一步可核对全部内容，任一项可跳回对应步骤修改。


关于页（新）
--

* **导航栏新增「关于」**，集中展示版本、版权与常用链接，并收纳问题反馈、更新日志、运行日志、回声洞、条款与授权。

* 反馈中心与更新日志不再各占一颗底部导航项，统一从「关于」进入。

* 本地品牌与站点、作者主页、赞助入口统一放在这一页。


侧边栏（新）
--

* **新增四个常用系统入口**：文件资源管理器、运行、屏幕键盘、锁定电脑，单击即打开。

* **新增 PowerPoint 触控按钮**：单击弹出菜单，可直接开关「触控手势」与「长按菜单」，不必进入设置页。上课中途需要立刻关掉误触时，这一步比翻设置快得多。


课表导入
--

* **CSES 课表同时支持 JSON 与 YAML**。此前只认 JSON，而课表工具导出的文件常为 `.yml`，用户手上有课表却导不进来。现在按文件内容判断格式，改过后缀同样可用。

* 文件选择框补上 `.yml` / `.yaml`。


文档库
--

* **支持表格、任务列表与删除线**。任务列表的完成项会同时划掉并淡化，不只依赖方框区分。

* 表格过宽时可**横向滚动**。此前列多或单元格长的表格在窄窗口里会被压缩成一列一个字。


磁盘空间
--

* **改为一次扫描建立完整目录结构**，进入任意一层直接显示，不再重新读盘。此前每进一层都要等一次扫描，深一点的路径需要反复等待。


网页工具
--

* **退出网页工具后释放其占用的内存**。此前每打开一次就留下一个渲染进程，长期使用会累积占用。现在离开时先挂起，闲置十分钟未回来才真正释放，再次打开则直接恢复，不必重新加载。


屏幕亮度
--

* **修复「亮度怎么调都回到同一个数」**。此前写入后未确认是否真的生效，系统亮度未变时程序却记为已生效，随后轮询读回旧值把滑块弹回。现在写入后回读校验，未生效则不记为成功。

* 用户刚调节过亮度的一小段时间内不采用系统读回值，避免写入尚未完成时把滑块弹回。

* 对只能通过软件方式调节亮度的机器，以程序记录值为准。软件调光不反映在系统读数中，此前会显示与画面不一致的数值。


投稿向导的两处修正
--

* **底部按钮文案正确显示**：第一步为「开始填写」，末步为「提交」，提交成功后变为「关闭」。

* **软件 ID 会随名称实时生成**。此前页面构建时机早于窗口显示，输入事件未生效，导致名称已填但 ID 始终为空。


运行前提（Windows 7 必看）
--

Windows 7 上除了 SP1，还需要一个系统更新：

| 更新 | 必要性 | 说明 |
| --- | --- | --- |
| **KB3063858** | **必须** | 早期版本号 KB2533623，现已并入后续累积更新。它给系统补上 `SetDefaultDllDirectories` 等一组 DLL 目录 API —— .NET 6 运行时靠这组 API 加载自己的组件。 |

缺这个更新的表现：双击程序**闪一下就退出**，界面上没有任何提示；打开「事件查看器 → Windows 日志 → 应用程序」能看到「事件 1023，.NET Runtime」，详细信息形如 `Failed to load the dll from [...hostfxr.dll]`、HRESULT `0x80070057`。

解决办法：到微软更新目录（catalog.update.microsoft.com）搜 `KB3063858` 装上，装完提示重启就重启。教室里的机器一般由管理员统一打补丁，把这个编号告诉老师即可。

已知限制
--

* **投稿向导的上传与提交流程未经真机验证**：上传依赖站点存储服务、提交需要激活，开发环境不具备这两个条件，仅完成代码审查与编译验证。建议首次使用时先提交一条测试内容确认流程通畅。

* **PPT 笔模式识别的 COM 链路未在真机实测**：读 `SlideShowView.PointerType` 这段代码已移植并编译通过，但「真能读到 PowerPoint 的指针类型」必须在装了 PowerPoint 并实际放映的机器上确认。读不到时会自动降级为「按箭头处理」，不影响其他功能。

* **关于页未移植顶部横幅**：上游该页有一条铺满顶部的渐隐横幅，依赖 WinUI 3 的合成层遮罩。Avalonia 无等价 API，软件渲染下代价较高，故本版不含该横幅，其余内容一致。

* 「残留清理」的提权清单仍是「同用户可写目录 → 管理员进程读取」的模型，理论上同用户进程可在 UAC 弹窗期间替换清单。这是已知的加固项，后续版本会改为助手侧重算候选。

* 教室喊话的局域网凭证目前是明文广播，仅适用于可信内网。
