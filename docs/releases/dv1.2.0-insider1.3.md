# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.3 预览版发布

前言
--

* 本版为 **dv1.2.0 预览线第四个版本**，也是本移植版迄今改动范围最大的一次：以 2026-10-26 的全量代码审计（约 9 万行）为基础，修复了全部 6 项 P0 缺陷，并处理了绝大多数 P1、P2 问题（少数需服务端配合或涉及结构性重构的项除外），同时对窗口材质、更新下载链路、教室喊话与教学工具做了集中改进。

* 教室喊话由「课堂工具」提升为导航栏独立功能，并同步上游 dv1.2.0-insider1.5 的双分页与局域网通道；软件下载页新增系统筛选，投稿页新增适用系统选择；其余界面与交互继续与原版保持一致。

* 预览版面向 insider 通道用户，用于在正式版发布前验证新功能与修复；若你正在使用 dv1.2.0-insider1.2，建议升级。

更新日志
----

* 【新增】**教室喊话 · 独立入口与双分页**：教室喊话移至导航栏，与「侧边布局」并列，不再放在「课堂工具」子项中；页面分为「接收」「发送」两页。「接收」页提供本机标识、配对码复制与本机预览（短消息 / 长消息 / 不带署名）；「发送」页可勾选已保存的电脑或直接填写配对码，发送结果按「局域网直达 / 服务器中转 / 失败」分别统计。

* 【新增】**教室喊话 · 局域网通道**：同一网段的电脑自动互相发现并直接投递，提供防火墙一键放行；跨网段时自动回落服务器通道。保存配对码时可在服务端登记，接收页可查看并移除「保存过本机配对码」的设备。

* 【新增】**教室喊话 · 接收设置与提示音**：提示音支持选择本地音频、试听、恢复默认与静音；新增显示间隔、安静模式（只弹窗不发声）、中文朗读、出场方式（打字机 / 按行交错划入 / 弹入 / 不带动画）与默认显示页。

* 【新增】**网页版工具宿主页**：本地 HTML 工具包以网页形式运行；WebView2 不可用或加载失败时静默回退到原生页面，不影响其它功能。学科工具窗口与导航栏工具入口同样按「网页优先、原生兜底」选择载体，降级过程无提示。

* 【新增】**Hub AI · 工具调用授权**：助手执行会改动本机状态的操作前，先弹出授权对话框，可选择允许或拒绝；拒绝后本轮对话继续，不影响后续提问。

* 【新增】**Hub AI · 停止与重新生成**：生成过程中可随时停止；任一轮回答可「重试」生成兄弟回答，或按 ↑ 将上一条提问拉回输入框编辑后重发（新开分支，原内容保留）。同一位置存在多个版本时，气泡下方以「‹ 1/2 ›」切换。

* 【新增】**Hub AI · 输入区**：输入框改为无边框渐变样式，发送与停止使用矢量图标；会话生成改为独立运行时对象，生成过程中切换页面或会话不再中断，返回后可直接查看结果，会话结束时自动存档。

* 【优化】**窗口拖动与材质**：修复 Windows 10/11 上标题栏无法拖动的问题，恢复拖动移窗、双击最大化、拖至屏幕边缘吸附与顶边调整大小；Windows 10 亚克力改用系统合成背板，Windows 11 亚克力与云母改用受支持的 DWM 材质，深色模式下不再出现整窗发灰或标题区发黑。常用工具窗口在所有系统上改为自绘标题栏，不再出现原生关闭 / 最小化 / 最大化按钮，并补齐圆角；Win10/11 上悬浮窗与无边框窗口的圆角改由面板透明通道裁出，不再出现方角。

* 【优化】**浮窗与侧边栏动画**：滑入、滑出改为 8 毫秒帧间隔，并在动画期间提升系统计时精度，展开与收起不再一顿一顿；侧边栏或浮窗滑动、主窗口不在前台时，首页装饰性重绘自动暂停，降低占用。

* 【优化】**侧边栏**：展开与收起改为从屏幕外滑入的贴边锚定，未钉住时点击其它区域即收起（含触摸）；网格翻页控件移至网格下方独立一行，不再遮挡首末列或吞掉点击；导航图标由 20 放大至 24；收起过程中的重复收起不再跳过淡出；滑动翻页不再误触发工具。

* 【优化】**首页**：图标下载纳入加速线路并统一本地缓存，同一图标不再重复请求，加载完成后推荐卡片即时更新；后台检查到新版本时，更新卡片无需重新进入首页即可刷新；推荐条在切换页面或主窗最小化时暂停刷新。

* 【优化】**搜索**：忽略横杠、空格、点号等分隔符（输入「7 zip」可命中「7-Zip」），多个关键词顺序无关；「教室喊话」加入顶层搜索项。

* 【优化】**软件下载页**：新增系统筛选下拉（「全部系统」与各平台，仅有一个平台时自动隐藏）；卡片宽度随可用宽度自适应；滚动条改为隐藏，滚轮与触摸滚动行为不变。

* 【优化】**投稿页**：新增「适用系统」多选项（按内容包平台清单生成），原「系统限制」改为选填的「系统说明」；从仓库导入时自动勾选识别到的平台；提交前校验至少选择一项适用系统。

* 【优化】**更新与下载**：安装包在安装前重新校验哈希，不一致时删除并提示重新下载；下载与更新增加 45 秒空闲超时，断流不再永久挂起；自建加速线路的接口密钥随候选线路透传，服务端代签增加单次超时；提交服务改为三入口依次尝试并记住上次成功的入口，单入口超时后立即切换；「保留 N 个安装包」不再淘汰待安装的包；更新安装不再恢复用户已删除的桌面图标；下载页会显示上次下载后尚未安装的更新包任务。

* 【优化】**兼容性体检**：Microsoft Store 应用单独统计（「另有 N 个 Microsoft Store 应用」），并补充检测口径说明：读取「程序和功能」的 64 位、32 位与当前用户三处安装记录，以及本账户注册的商店应用；免安装版本、已更名软件及其他账户下安装的应用不在统计范围内。

* 【优化】**站点与网络**：官网地址与内容清单地址统一切换至 classsoftwarehub.cn，内容清单备用源同步更新；出网请求统一显式启用 TLS 1.2（Windows 11 追加 TLS 1.3），Windows 7 上不再出现「检查更新 / 提交永远网络错误」。

* 【优化】**时钟工具**：字体列表改为按本机已安装字体过滤，材质选项统一标注为「近似」，不再出现选择与实际显示不一致；背景图解码结果加入缓存，拖动外观滑块不再重复解码原图。

* 【优化】**设置页更新卡**：设置页不再整篇渲染发版正文，卡片只保留按钮、进度与一行状态；更新说明改由更新对话框展示，避免长文与配图链接撑满整页。

* 【修复】**教室喊话**：长文字启用「按行交错划入」时字号过小且不随窗口缩放调整；喊话窗改用内嵌 HarmonyOS Sans SC 字体，不再因字体资源缺失而无法打开；配对码连续输错 5 次后锁定 2 分钟。

* 【修复】**数学与化学**：修正 `√x` 型函数的零点结论、数值求根遗漏偶重根并产生假根、角度制三角零点输出不存在的角、离子方程式无法配平、奇偶性证明失败被误判为非奇非偶、同号无穷处曲线不断线等问题。

* 【修复】**安全与稳定性**：残留清理不再把用户目录当作可删除残留，备份失败时不再强删源目录；修复单实例接管失败后可能同时运行两个实例的问题；发布版未处理异常改为限流提示，不再静默无响应；第三方网页的桥接消息增加来源校验；AI 网页工具禁止访问内网与环回地址，磁盘扫描拒绝 UNC 与网络路径；喊话配对码连续输错触发锁定。

* 【修复】**桌面与系统**：托盘图标注册失败时退避重试，仍失败则提示具体原因（如资源管理器以管理员身份运行导致完整性级别不一致）与解决方法；托盘不可用时点击关闭改为最小化并说明，再次关闭才真正退出；开机自启项指向已安装版本而非构建输出目录；修复启动器在缺少 app 目录时自我拉起、进程链不断的问题；贴图按截取位置与尺寸显示；时钟页拖动滑块不再泄漏位图；兼容性体检与投稿失败后不再永久停留在加载状态；虚拟键盘可重复显示；截图编辑器关闭后释放资源；系统修复页离开后停止轮询；后台下载更新时任务卡片与进度显示恢复正常；Windows 7 上滑动关机不可用时回退为普通关机，剪贴板历史等不可用操作给出提示；系统修复项按系统版本过滤，不再展示当前系统不支持的项目。

* 【修复】**工具与交互**：抽号滚动过程中清空或更换名单不再触发索引越界，离开页面后按钮状态恢复；导入名单最多读取 8 MB，误选大文件不再整份读入内存；磁盘空间页启动只扫描一次，取消与重新扫描不再互相覆盖状态；从首页卡片、搜索结果或详情页跳转后，左侧导航高亮正确同步；设置卡片改为抬手判定并带位移容差，滑动时不再误入法律条款；触摸滚动结束时不再被识别为点击；多个下载同时完成时通知不再重复或遗漏；图片取色预览按 480 像素宽解码并释放旧图，大端序 EXIF 的竖拍照片方向正确；编码工具对长文本改为停止输入 150 毫秒后计算哈希，粘贴大段文本不再卡顿；应用数据页切换分类不再重复订阅状态变化，反馈页只初始化一次。
