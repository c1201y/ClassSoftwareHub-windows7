# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.3 预览版发布

前言
--

* 本版为 **dv1.2.0 预览线第四个版本**，也是本移植版迄今改动范围最大的一次：在 2026-10-26 的全量代码审计（约 9 万行）基础上，修复了全部 P0 缺陷与绝大多数 P1 缺陷，并完成窗口材质、更新下载链路、教室喊话与教学工具的多项改进。

* 教室喊话同步上游 dv1.2.0-insider1.5 的双分页与局域网通道；其余界面与交互继续与原版保持一致。

* 预览版面向 insider 通道用户，用于在正式版发布前验证新功能与修复；若你正在使用 dv1.2.0-insider1.2，建议升级。

更新日志
----

* 【新增】**教室喊话 · 局域网通道**：接收页新增局域网直达通道与防火墙一键放行，发送页可自动发现同网段设备、手动填写配对码并保存为常用电脑；发送时同网段直达、跨网段自动回落服务器通道。

* 【新增】**教室喊话 · 接收设置**：新增提示音选择与静音、显示间隔、安静模式、朗读、出场方式、本机标识与本机配对码管理，并可查看和移除「已保存本机配对码」的设备。

* 【新增】**工具宿主页**：本地 HTML 工具包以网页形式托管运行，初始化或加载失败时静默回退到原生页面，不影响其它功能。

* 【新增】**AI 会话运行时**：对话生成改为独立于页面的运行时对象，生成过程中切换页面或会话不再中断，返回后可直接查看结果；会话结束时自动存档。

* 【优化】**窗口拖动与材质**：修复 Windows 10/11 上标题栏无法拖动的问题，恢复拖动移窗、双击最大化、拖至屏幕边缘吸附与顶边调整大小；Windows 10 亚克力改用系统合成背板，Windows 11 亚克力与云母改用受支持的 DWM 材质，深色模式下不再出现整窗发灰或标题区发黑。

* 【优化】**侧边栏**：展开与收起改为贴边锚定，未钉住时点击其它区域即收起（含触摸）；网格翻页控件移至网格下方独立一行，不再遮挡首末列或吞掉点击；导航图标由 20 放大至 24；滑动翻页不再误触发工具。

* 【优化】**首页推荐应用图标**：图标下载纳入加速线路并统一本地缓存，同一图标不再重复请求；图标加载完成后推荐卡片即时更新，无需重新进入首页。

* 【优化】**更新与下载**：安装包在安装前重新校验哈希；下载与更新增加 45 秒空闲超时，断流不再永久挂起；自建加速线路的接口密钥随候选线路透传；设置保存加锁，避免并发写入丢失；Windows 7 显式启用 TLS 1.2。

* 【优化】时钟工具字体列表改为按本机已安装字体过滤，材质选项统一标注为「近似」，不再出现选择与实际显示不一致。

* 【修复】**教室喊话**：长文字启用「按行交错划入」时字号过小且不随窗口缩放调整；喊话窗因字体资源缺失而无法打开。

* 【修复】**数学与化学**：修正 `√x` 型函数的零点结论、数值求根遗漏偶重根并产生假根、角度制三角零点输出不存在的角、离子方程式无法配平、奇偶性证明失败被误判为非奇非偶、同号无穷处曲线不断线等问题。

* 【修复】**安全与稳定性**：残留清理不再把用户目录当作可删除残留，备份失败时不再强删源目录；修复单实例接管失败后可能同时运行两个实例的问题；发布版未处理异常改为限流提示，不再静默无响应；第三方网页的桥接消息增加来源校验；AI 网页工具禁止访问内网与环回地址；喊话配对码连续输错触发锁定。

* 【修复】**桌面与系统**：贴图按截取位置与尺寸显示；时钟页拖动滑块不再泄漏位图；兼容性体检与投稿失败后不再永久停留在加载状态；虚拟键盘可重复显示；截图编辑器关闭后释放资源；系统修复页离开后停止轮询；Windows 7 上滑动关机不可用时回退为普通关机，剪贴板历史等不可用操作给出提示；系统修复项按系统版本过滤，不再展示当前系统不支持的项目。
