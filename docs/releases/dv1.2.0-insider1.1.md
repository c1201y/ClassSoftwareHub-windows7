# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.1 预览版发布

前言
--

* 这是 Windows 7 移植版 **dv1.2.0 预览线的第二个版本**：在 dv1.2.0-insider1.0 基础上集中修正方程求解的分数排版与「修改方程」浮层的图标问题。

* 预览版面向 insider 通道用户，用于在正式版发布前验证新功能与修复；发现问题可在反馈中心提交。

更新日志
----

* 【修复】方程求解结果的**分数排版**：分数改为自绘排版，分数线居数学轴、分母垂到基线以下，不再出现分母被裁剪、分数压在基线上与前面数字挤成一排的问题（三角方程、一次方程组的分数解均恢复正常）。[by@椰汁](https://afdian.com/a/cyan1201)

* 【修复】「修改方程」浮层中**退格键图标方向错误**（显示为上箭头），已更正为删除（⌫）图标。[by@椰汁](https://afdian.com/a/cyan1201)

* 【修复】函数分析、化学配平等复用同一排版器的页面，上标与根号在长式子里的基线同步对齐。[by@椰汁](https://afdian.com/a/cyan1201)
