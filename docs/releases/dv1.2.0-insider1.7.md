# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.7 预览版发布

前言
--

* 本版为 **dv1.2.0 预览线的新版本**，在 dv1.2.0-insider1.6 的基础上补充崩溃与卡顿的诊断能力、在线状态上报与运行日志规范化，并修复学科工具首次打开时的窗口黑边。

* 官方发布包自带构建签名，在线服务无需任何操作即可使用。自行编译或改动过的版本，使用在线功能（软件投稿、反馈中心、回声洞、教室喊话、下载加速）时需要输入激活码。

* 预览版面向 insider 通道用户。若正在使用 dv1.2.0-insider1.6，建议升级。

更新日志
----

* 【新增】**运行状态上报**：客户端每 60 秒上报一次在线状态，与教室喊话开关无关。管理后台据此统计在用设备，并区分「可接收喊话」与「仅在线」。

* 【新增】**崩溃转储**：针对访问冲突、栈溢出、FailFast 等不经过托管异常通道的崩溃，注册系统本地转储与 .NET 运行时转储。启动器在拉起主程序前注入相关开关，崩溃现场可直接用于事后分析。

* 【新增】**界面卡死记录**：后台线程周期性探测 UI 线程的排队延迟，超过阈值时记录卡顿时长、所在页面、内存与线程池读数，用于定位「暂时无响应、随后自行恢复」一类问题。

* 【新增】**异常退出识别**：每次运行在会话目录写入存活标记，正常退出时删除。下一次启动若发现标记残留，说明上次未走完退出流程，日志中会注明。

* 【优化】**日志规范化**：日志正文统一为「对象 + 动作 + 字段」句式，模块名收敛为固定取值；移植期打点并入同一份日志，不再单独生成 port.log；预期内的失败记录异常类型，非预期异常记录完整堆栈。

* 【新增】**设备标识**：在线请求携带硬件锚定的设备标识（Windows 10 1607 及以上取系统发布者标识，Windows 7 取安装标识与系统卷序列号），供服务端做信誉判定与设备封禁。

* 【修复】**学科工具窗口黑边**：窗口首次显示后补一次背景擦除，并按当前客户区重建渲染表面，不再需要拖动窗口才能恢复。

* 【优化】**留言悬浮窗**：系统不支持逐像素透明时改用色键抠底，保持全透明显示，该档位不再绘制圆角边框。

* 【优化】**工具侧栏**：图标网格样式新增「网格图标大小」设置（48～96 dip），翻页与收起增加淡出、淡入与滑出过渡。

* 【优化】**窗口材质**：Windows 10 1803 以下与远程桌面会话改用壁纸模糊底色；新增启动参数 `--simulate-win10`，用于在 Windows 11 上验证 Windows 10 的材质分支。

* 【修复】**切换页面卡顿**：切换页面时只回收托管内存，不再回收工作集，避免清除刚渲染的页面资源后重新读盘。

* 【优化】**下载与更新日志**：仅记录主机名，不写入带签名参数的完整链接，避免临时凭证落入日志文件。
