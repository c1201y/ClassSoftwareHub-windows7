# ClassSoftwareHub 桌面版（Windows 7）dv1.2.0-insider1.4 预览版发布

前言
--

* 本版为 **dv1.2.0 预览线的新版本**，新增「文件快搜」与「PPT 续播」两项功能，并包含 dv1.2.0-insider1.3 发布说明列出的全部改进。

* **文件快搜**在本机后台建立文件索引并缓存，不联网；除工具页外，可从屏幕边缘侧边栏、托盘菜单或独立浮窗使用。

* **PPT 续播**按科目记录课件的放映页码，配合 CSES 课表可在下次上课时从上次停下的那一页继续放映；所有记录仅保存在本机。

* 预览版面向 insider 通道用户。若正在使用 dv1.2.0-insider1.3，建议升级。

更新日志
----

* 【新增】**文件快搜**：输入关键词即时列出本机文件与文件夹，结果显示大小、修改日期与完整路径，支持复制路径、在资源管理器中定位与直接打开。多个关键词以空格分隔，顺序无关。

* 【新增】**文件快搜 · 索引与浮窗**：后台遍历固定与可移动磁盘（最多 60 万项），索引缓存在本机；缓存有效期 24 小时，过期后在后台重建，重建期间旧索引仍可使用。索引范围可按磁盘勾选，也可手动重建；系统目录默认排除。提供独立浮窗，可置顶、可缩放，与工具页共用同一份索引。

* 【新增】**PPT 续播**：放映期间每 2 秒记录当前页码，课件关闭或切换科目后进度不丢失；再次上课时可从上次页码继续放映。支持 PowerPoint 与 WPS 演示，也可手动为科目指定课件。

* 【新增】**PPT 续播 · CSES 课表**：支持导入 CSES 课表（JSON），按单双周推算当前课程并显示当前科目；也可不导入课表，直接按科目续播。

* 【新增】**托盘菜单**：右键托盘图标改为 Fluent 风格自绘菜单，含图标与快捷键操作，新增「文件快搜」入口；自绘菜单不可用时自动回退系统菜单。

* 【优化】**桌面留言**：界面改为与教室喊话一致的标题行与单列卡片布局，全部设置集中在一页，窄屏下不再挤压。

* 【优化】**窗口与侧边栏**：桌面留言悬浮窗与工具侧边栏不再出现在任务管理器的「应用」列表中；侧边栏展开面板与屏幕边缘保留 5 DIP 间距；收起态的圆角抓手恢复为上游规格（标准 20×110 DIP、紧凑 12×72 DIP，内芯 5×48 / 4×34），收起态不绘制描边。

* 【修复】**Windows 7 选择文件崩溃**：手写 IFileDialog 互操作在失败 HRESULT 下仍封送未初始化的字符串指针，导致访问冲突（0xC0000005）。现改回 Avalonia 存储选择器路径，并补充失败分支处理。

* 【修复】**编码工具重复弹窗**：点击「选择文件」会连续弹出两次文件对话框，原因为按钮点击继续冒泡到拖放区；现忽略来自按钮的点击。

* 【修复】**提示音**：补上教室喊话默认提示音缺失的内嵌资源；修复倒计时与喊话在进程异常退出后不再发声；wav 改由 PlaySound 播放，MCI 作为非 wav 与异常环境的兜底。

* 【修复】**文件索引 0 项**：磁盘根路径结尾的反斜杠被裁剪，导致枚举结果为空；现保留根路径，并在与设置中的磁盘列表比对时统一归一。

* 【修复】**导航自检误报**：内置工具与导航分组的校验改为集合比较，不再每次启动误报不一致。

* 【同 1.3】教室喊话（导航独立入口、双分页、局域网通道、接收设置与提示音）、Hub AI（工具调用授权、停止与重新生成、输入区）、网页版工具宿主页、窗口拖动与材质、浮窗与侧边栏动画、首页图标缓存与更新卡片、搜索分隔符兼容、软件下载页系统筛选、投稿页适用系统、更新下载校验与超时、兼容性体检、站点 TLS 1.2、时钟工具与设置页更新卡，以及安全、数学化学、桌面系统与工具交互方面的修复，详见 dv1.2.0-insider1.3 发布说明。
